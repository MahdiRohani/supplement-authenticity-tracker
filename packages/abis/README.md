# Shared ABIs

Generated by `contracts` deploy (`npm run deploy:local`).

`SupplementRegistry.json` fields:

- `abiVersion` — semver label for backend/Android sync (current: `1.1.0`)
- `address`, `chainId`, `network`, `abi`

Keep backend `REGISTRY_ABI_PATH` and Android chain verifier in sync with this file after each contract ABI change.
