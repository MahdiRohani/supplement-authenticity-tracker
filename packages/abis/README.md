# Shared ABIs

Generated by `contracts` deploy (`npm run deploy:local`).

`SupplementRegistry.json` fields:

- `abiVersion` — semver label for backend/Android sync (current: `1.3.0`)
- `address`, `chainId`, `network`, `abi`

`deployments.json` maps `chainId → { network, address, abiVersion }` for multi-chain clients and `GET /v1/chains`.

Bump `abiVersion` on any ABI-breaking or additive public interface change. Keep backend `REGISTRY_ABI_PATH` and Android chain verifier in sync with this file after each contract ABI change.

API surface remains `/v1` while major stays `1.x`.
